# TPL_RACI — Matriz RACI

> **Propósito:** formato de matriz de responsabilidades RACI del contrato.
> **Cuándo cargarlo:** diseño de gobernanza (Skill 07).
> **Skills:** 07_GOVERNANCE_DESIGNER. **Prioridad:** alta. **Coste:** bajo.
> **Resumen:** matriz RACI por procesos reales con roles de ambas partes (adjudicatario y órgano) y las reglas de construcción de K-11 §3.

---

## Formato

| Proceso / decisión | Dir. proyecto (adj.) | Jefe equipo (adj.) | Técnico (adj.) | Resp. contrato (órgano) | Comisión seguimiento |
|---|---|---|---|---|---|
| Aprobar plan de trabajo ajustado | C | R | | **A** | I |
| Elaborar entregable [tipo] | I | C | R | | |
| Validar entregable | C | R | | **A** | I |
| Autorizar cambio de alcance | C | C | | **A** | I |
| Gestionar incidencia operativa | I | **A** | R | C | |
| Comunicación pública de resultados | C | C | | **A** | I |

**R** = realiza · **A** = aprueba/responde (una sola por fila) · **C** = consultado antes · **I** = informado después

## Reglas de uso

Filas = procesos y decisiones con enjundia (no tareas triviales) · una sola **A** por fila · el órgano SIEMPRE está en la matriz (sus validaciones son la palanca contra bloqueos, K-11 §3) · roles = perfiles reales del equipo ofertado (RI-04) · coherencia con el modelo de comités y el circuito de escalado del mismo apartado.
